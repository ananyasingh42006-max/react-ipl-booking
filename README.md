
# 🏏 IPL Ticket Booking Website

A React JS based IPL Ticket Booking Website developed using React and Vite.

## ✨ Features

- Navigation bar with Home, Matches and Booking History.
- Hero section with Explore Matches button.
- Displays upcoming IPL matches.
- Reusable MatchCard components.
- Match information passed using Props.
- Multiple match cards displayed using map().
- Dynamic booking count using useState.
- Book Ticket and Sold Out buttons.
- Responsive website design.

## 🛠️ Technologies Used

- React JS
- JavaScript
- JSX
- CSS
- Vite
- GitHub

## 🚀 How to Run the Project

### Step 1: Clone the Repository

```bash
git clone https://github.com/ananyasingh42006-max/react-ipl-booking.git
```

### Step 2: Open Project Folder

```bash
cd react-ipl-booking/match-booking
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start Development Server

```bash
npm run dev
```

### Step 5: Open Website

```text
http://localhost:5173/
```
